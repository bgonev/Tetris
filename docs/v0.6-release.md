# Tetris CPC v0.6 Release Notes

Version 0.6 keeps the DSK-only direct-FDC overlay model from v0.5 and promotes
the mock-inspired gameplay screen work to an official release. It also moves the
menu/redefine-key code back into resident RAM to remove the game-over to menu
reload delay.

## User Entry Point

Insert `dist\TETRIS.DSK` or `dist\TETRIS-v0.6.DSK` and run:

```basic
RUN"TETRIS.BIN"
```

The visible catalog intentionally contains only the small boot file. The
resident game payload and runtime overlays are stored in fixed hidden sectors.

## Official Build

Use:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\build_overlay_dsk.ps1
```

Main outputs:

- `dist\TETRIS.DSK`: current v0.6 release disk.
- `dist\TETRIS-v0.6.DSK`: versioned v0.6 release disk.
- `dist\TETRIS.BIN`: AMSDOS-headered direct-FDC boot file for reference.
- `dist\TETRIS-v0.6.BIN`: versioned copy of the boot file.

There is no v0.6 CDT artifact because the v0.6 loader relies on disk sectors.
Keep v0.4 as the monolithic/CDT-friendly build.

## Current Memory Layout

- Resident game payload: `0x1000-0x3217`, 8728 bytes.
- Resident payload sectors: 18 sectors, tracks 20-21.
- Boot loader: load/run `0x0800`, 851 bytes.
- Gameplay screen overlay: load `0xC000`, 16384 bytes, tracks 22-25.
- Splash/title overlay: load `0x5000`, 16175 bytes, tracks 30-33.
- Gameplay music overlay: load `0x9400`, 686 bytes, track 34.
- Runtime font/text/tables overlay: load `0x5000`, 864 bytes, track 35.
- Menu/redefine-key code: resident in the main payload.
- CPC screen RAM remains `0xC000-0xFFFF`.

Moving the menu code resident cost 921 bytes compared with the v0.5 menu-overlay
build, but removes the visible delay when returning from game over to the menu.

## Gameplay Screen

- Generated by `tools\generate_gameplay_background.ps1`.
- Source mock: `assets\new_gameplay_layout.jpg`.
- Preview output: `assets\gameplay_mode0_preview.png`.
- Runtime overlay binary: `obj\overlay\gameplay_screen.bin`, loaded to screen
  RAM at `0xC000`.
- `TETRIS` and `NEXT` labels use the same compact CPC sprite glyph style.
- The dedication text was removed from gameplay and moved to the centered boot
  loader message.

## Verified Behavior

- Direct-FDC boot reads the resident payload from hidden sectors.
- Splash/title overlay and title music load correctly.
- Runtime font/text/key tables reload after splash.
- Gameplay screen overlay loads before the board and HUD are drawn.
- Gameplay music stays persistent at `0x9400`.
- Menu/redefine-key flow runs resident, so returning from game over no longer
  performs the menu-code overlay reload.
